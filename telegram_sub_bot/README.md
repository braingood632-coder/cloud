# بوت Cloud لإدارة الاشتراكات المدفوعة عبر ميسر

بوت تليجرام كامل: يبيع اشتراكات (90 يوم / 50 ريال، 6 أشهر / 80 ريال)، يستقبل
الدفع عبر بوابة **ميسر (Moyasar)**، ويحمي قروب تليجرام موجود مسبقاً بحيث لا
يكتب فيه إلا المشتركون النشطون والأدمنية فقط. أي شخص آخر تُحذف رسالته فوراً
مع تنبيه له بضرورة الاشتراك، بالإضافة لرسالة تذكير دورية كل نصف ساعة داخل
القروب بالأسعار والباقات.

> **ملاحظة مهمة:** لم يتم تضمين أي آلية "تأكيد رقم الهاتف لمنع الاحتيال" عبر
> طلب مشاركة جهة الاتصال، لأن هذا الأسلوب يتطابق مع نمط معروف يُستخدم في
> بوتات احتيال حقيقية لجمع أرقام الهواتف واستغلالها. رقم الهاتف (إن احتجته)
> يمكن الحصول عليه بشكل شرعي من بيانات الدفع نفسها عبر ميسر عند الحاجة.

## هيكل المشروع

```
telegram_sub_bot/
├── config.py           # الإعدادات والباقات (السعر والمدة)
├── database.py         # قاعدة البيانات (SQLite/PostgreSQL) عبر SQLAlchemy
├── moyasar_client.py   # التعامل مع Moyasar Invoice API
├── bot_handlers.py     # منطق البوت: الترحيب، الباقات، حماية القروب
├── webhook_server.py   # سيرفر FastAPI (Webhook) + تشغيل البوت
├── main.py             # نقطة التشغيل: python main.py
├── requirements.txt
└── .env.example
```

## 1) التثبيت

```bash
python -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

افتح ملف `.env` وعبّئ القيم التالية:

| المتغير | من أين تحصل عليه |
|---|---|
| `BOT_TOKEN` | من [@BotFather](https://t.me/BotFather) بعد إنشاء بوت جديد بأمر `/newbot` |
| `MOYASAR_SECRET_KEY` | من [لوحة تحكم ميسر](https://dashboard.moyasar.com) → API Keys (استخدم مفتاح **Test** أثناء التجربة) |
| `MOYASAR_WEBHOOK_SECRET` | نص سري من اختيارك أنت (أي كلمة مرور قوية)، سنستخدمه لاحقاً في خطوة 3 |
| `PUBLIC_BASE_URL` | رابطك العام على الإنترنت (شرح كيفية الحصول عليه في خطوة 2) |
| `ADMIN_GROUP_ID` | آيدي القروب المراد حمايته، احصل عليه بإضافة [@userinfobot](https://t.me/userinfobot) للقروب مؤقتاً (نفس الآيدي يُستخدم أيضاً لإرسال رسالة التذكير الدورية) |
| `OWNER_TELEGRAM_ID` | معرفك الرقمي أنت (@radhadh91)، احصل عليه من [@userinfobot](https://t.me/userinfobot) في محادثة خاصة — يُستثنى دائماً من فحص الاشتراك |

## 2) الحصول على رابط عام (Public URL) لتشغيل الـ Webhook محلياً

ميسر لا يستطيع إرسال إشعارات إلى `localhost` على جهازك، لذا تحتاج رابطاً
عاماً. للتجربة استخدم **ngrok**:

```bash
# تحميل وتثبيت ngrok من https://ngrok.com/download
ngrok http 8000
```

سيعطيك ngrok رابطاً مثل: `https://abcd-1-2-3-4.ngrok-free.app`
ضع هذا الرابط في `.env` بالحقل `PUBLIC_BASE_URL` (بدون شرطة `/` في النهاية).

> **ملاحظة:** رابط ngrok المجاني يتغيّر في كل مرة تعيد تشغيله، لذا يجب تحديث
> `.env` وإعادة ضبط الـ Webhook في لوحة ميسر (خطوة 3) في كل مرة تعيد تشغيل
> ngrok. عند رفع المشروع على سيرفر حقيقي (VPS) لن تحتاج لهذه الخطوة، فقط
> ضع نطاقك الفعلي مباشرة.

## 3) ربط الـ Webhook في لوحة تحكم ميسر

1. ادخل إلى [dashboard.moyasar.com](https://dashboard.moyasar.com)
2. اذهب إلى **Developers → Webhooks**
3. اضغط **Add Webhook** واملأ:
   - **URL**: `PUBLIC_BASE_URL` الخاص بك + `/moyasar/webhook`
     مثال: `https://abcd-1-2-3-4.ngrok-free.app/moyasar/webhook`
   - **Secret Token**: نفس القيمة التي وضعتها في `MOYASAR_WEBHOOK_SECRET`
   - **Events**: فعّل حدث `invoice_paid` (تأكد منه، فقد يظهر باسم مشابه
     حسب واجهة اللوحة الحالية)
4. احفظ. ستجد في نفس الصفحة سجل كل الإشعارات المُرسلة (Deliveries) وهذا
   مفيد جداً لتتبع الأخطاء أثناء التجربة.

كيف يعمل التحقق؟ سيرفرنا في `webhook_server.py` يقرأ الهيدر
`x-moyasar-token` القادم مع كل طلب، ويقارنه بـ `MOYASAR_WEBHOOK_SECRET` في
ملفك، ويرفض أي طلب لا يطابقه بخطأ 401. هذا يمنع أي شخص من تزوير إشعار دفع
مزيف وتفعيل اشتراك مجاني.

> **تنبيه:** اسم الهيدر الفعلي وطريقة توقيع الإشعار قد يختلفان قليلاً حسب
> إصدار حساب ميسر لديك (بعض الحسابات تستخدم توقيع HMAC بدل توكن ثابت).
> راجع صفحة "Deliveries" في لوحتك لمعرفة الهيدر الحقيقي المُرسل، وعدّل
> اسم المتغير `x_moyasar_token` في `webhook_server.py` إذا لزم الأمر.

## 4) تشغيل المشروع

```bash
python main.py
```

سيقوم هذا الأمر بأمرين معاً في نفس الوقت:
- تشغيل بوت تليجرام (Polling) — لا تحتاج لتشغيله بأمر منفصل.
- تشغيل سيرفر FastAPI على المنفذ `8000` لاستقبال Webhook من ميسر.

تأكد من بقاء `ngrok` شغّالاً في نافذة طرفية أخرى طوال وقت الاختبار.

## 5) تجهيز البوت داخل تليجرام

1. أرسل `/start` للبوت في الخاص → ستظهر له الباقتان (90 يوم / 6 أشهر).
2. أضف البوت إلى القروب **الموجود مسبقاً** (لا داعي لإنشاء قروب جديد ولا
   لإرسال أي رابط دعوة — البوت لا يفعل ذلك إطلاقاً).
3. اجعله **مشرفاً (Admin)** في القروب، وفعّل له تحديداً صلاحية **حذف
   الرسائل (Delete Messages)** من إعدادات صلاحيات المشرف.
4. أي عضو يكتب في القروب ولم يشترك بعد (أو انتهى اشتراكه):
   - تُحذف رسالته فوراً تلقائياً.
   - يصله تنبيه في القروب باسمه يوضح أن القروب للمشتركين فقط، مع زر
     "📝 اشترك الآن" ينقله مباشرة لمحادثة البوت. هذا التنبيه يُحذف تلقائياً
     بعد 20 ثانية حتى لا يمتلئ القروب.
   - رسائل مالك البوت (`OWNER_TELEGRAM_ID`) ومشرفي/مالك القروب لا تُحذف أبداً.
5. كل 30 دقيقة (`GROUP_REMINDER_INTERVAL_SECONDS` في `config.py`)، يرسل
   البوت تلقائياً رسالة في القروب تُذكّر الجميع بالباقتين والأسعار والمدد،
   مع زر "📝 اشترك الآن".

## 6) سيناريو الدفع خطوة بخطوة

1. المستخدم يضغط زر باقة (مثلاً "باقة 3 أشهر - 50 ريال").
2. البوت يطلب من ميسر إنشاء فاتورة بقيمة 50 ريال، مع `expired_at` بعد
   30 دقيقة بالضبط من الآن (`config.py → INVOICE_EXPIRY_MINUTES`).
3. يحفظ سجلاً في قاعدة البيانات بحالة `pending` مرتبطاً برقم الفاتورة.
4. يرسل للمستخدم زر "💳 إتمام الدفع الآن" يفتح صفحة ميسر داخل نافذة
   **Telegram WebApp** (لا يخرج المستخدم من تطبيق تليجرام إطلاقاً).
5. عند نجاح الدفع، يرسل ميسر إشعار Webhook فورياً إلى `/moyasar/webhook`.
6. السيرفر يتحقق من التوكن السري، يفعّل الاشتراك في قاعدة البيانات
   (تاريخ البداية = الآن، تاريخ النهاية = الآن + مدة الباقة)، ثم يرسل
   للمستخدم رسالة "✅ تم تفعيل اشتراكك بنجاح!".
7. من هذه اللحظة يستطيع الكتابة في القروب دون أن تُحذف رسائله.
8. إذا لم يدفع خلال 30 دقيقة، تنتهي صلاحية الفاتورة تلقائياً من طرف ميسر
   ولا يتم تفعيل أي شيء.

## 7) إعداد بروفايل البوت (الاسم والوصف) عبر BotFather

هذه الخطوة لا علاقة لها بالكود، إنما تُضبط من داخل محادثتك مع
[@BotFather](https://t.me/BotFather) مباشرة، وتتحكم بما يظهر للمستخدم في
صفحة معلومات البوت (بروفايله) قبل أن يضغط "Start":

1. أرسل `/setname` لـ BotFather واختر البوت → اكتب `Cloud`
2. أرسل `/setdescription` (هذا النص يظهر للمستخدم **قبل** أن يبدأ محادثة
   مع البوت):
   ```
   بوت Cloud لإدارة الاشتراكات في القروب. اضغط Start لعرض الباقات المتاحة والاشتراك.
   ```
3. أرسل `/setabouttext` (هذا النص يظهر في صفحة "معلومات البوت" الجانبية):
   ```
   بوت Cloud — يدار من قبل @radhadh91.
   لأي استفسار أو مشكلة تخص الاشتراك تواصل مباشرة مع @radhadh91.
   ```
4. أرسل `/setuserpic` لرفع شعار جديد بدل أي شعار قديم مرتبط بأي جهة أخرى.

بهذا الشكل لا يظهر أي اسم شركة أو أي معلومات غير متعلقة بك أو بالبوت.

## 8) النشر على Render

نعم، **Render يكفي تماماً** لتشغيل هذا البوت (خدمة واحدة تشغّل البوت
والـ Webhook معاً بنفس العملية عبر `python main.py`). خطوات النشر:

### أ) رفع المشروع

Render يحتاج المشروع في **مستودع Git** (GitHub غالباً)، لا يقبل رفع ملف
zip مباشرة:

1. أنشئ مستودعاً جديداً فارغاً على [GitHub](https://github.com/new).
2. ارفع كل ملفات المشروع إليه **ما عدا ملف `.env`** (لا ترفعه إطلاقاً، فيه
   مفاتيحك السرية). أضف ملف `.gitignore` يحتوي على السطر: `.env`

### ب) إنشاء الخدمة في Render

1. من لوحة Render اضغط **New → Web Service** واختر المستودع.
2. **Build Command**: `pip install -r requirements.txt`
3. **Start Command**: `python main.py`
4. اختر أي خطة (Free تكفي للتجربة، لكن اقرأ التنبيه في الفقرة (د) بالأسفل).

### ج) 🔑 أين تحط مفاتيحك السرية؟ (MOYASAR_SECRET_KEY وغيره)

**لا تضعها في أي ملف داخل المشروع أو المستودع أبداً.** ضعها فقط من داخل
لوحة Render نفسها:

1. داخل صفحة الخدمة التي أنشأتها → تبويب **Environment**.
2. اضغط **Add Environment Variable** وأضف كل متغير من ملف `.env.example`
   بشكل منفصل (المفتاح والقيمة)، مثل:
   - `BOT_TOKEN`
   - `MOYASAR_SECRET_KEY`
   - `MOYASAR_WEBHOOK_SECRET`
   - `ADMIN_GROUP_ID`
   - `OWNER_TELEGRAM_ID`
   - `BOT_NAME`, `CHANNEL_NAME`
   - `DATABASE_URL`
3. متغير `PUBLIC_BASE_URL`: بعد أول نشر ناجح، Render يعطيك رابطاً تلقائياً
   شكله `https://your-app-name.onrender.com` — انسخه وضعه كقيمة لهذا
   المتغير، ثم اضغط **Manual Deploy → Deploy latest commit** لإعادة النشر.
4. **لا تحتاج متغير `PORT`** — Render يضبطه تلقائياً بنفسه، والكود مُعدّل
   مسبقاً (`config.py`) ليقرأه وحده تلقائياً.

هذا يضمن أن مفاتيحك لا تُخزَّن أبداً في أي ملف يمكن لأي شخص آخر رؤيته لو
اطّلع على المستودع.

### د) ⚠️ تنبيه مهم بخصوص قاعدة البيانات على Render

خطة Render المجانية (Free) تحذف كل الملفات المحلية (ومنها ملف
`subscribers.db` الخاص بـ SQLite) في كل مرة يُعاد فيها تشغيل الخدمة أو
نشر تحديث جديد، لأن التخزين فيها غير دائم (Ephemeral). يعني ممكن تفقد كل
بيانات المشتركين فجأة.

**الحل الموصى به:** استخدم قاعدة بيانات PostgreSQL مجانية من Render نفسه:

1. من لوحة Render: **New → PostgreSQL** وأنشئ قاعدة مجانية.
2. انسخ رابط الاتصال (Internal Database URL) الذي يعطيك إياه Render.
3. غيّر بدايته من `postgresql://` إلى `postgresql+asyncpg://` وضعه في متغير
   `DATABASE_URL` بخدمة البوت (Environment tab).
4. أضف `asyncpg` إلى `requirements.txt`.

بهذا لا تفقد بيانات المشتركين أبداً حتى مع إعادة النشر أو إعادة التشغيل.

### هـ) ربط Webhook ميسر برابط Render

نفس خطوة (3) بالأعلى، لكن استخدم رابط Render بدل ngrok:
`https://your-app-name.onrender.com/moyasar/webhook`

## 9) الترقية إلى PostgreSQL (اختياري، محلياً أو خارج Render)

غيّر فقط في `.env`:

```
DATABASE_URL=postgresql+asyncpg://username:password@localhost:5432/subscribers_db
```

وأضف الحزمة التالية إلى `requirements.txt`:

```
asyncpg
```

لا حاجة لتعديل أي كود آخر، لأن `database.py` مبني بشكل عام (Engine-agnostic).

## 10) أفكار للتوسعة لاحقاً

- طرد المستخدم فعلياً من القروب (وليس فقط حذف رسائله) عند انتهاء الاشتراك،
  عبر استدعاء `bot.ban_chat_member` ثم `unban_chat_member` مباشرة.
- تنبيه المستخدم قبل 3 أيام من انتهاء اشتراكه لتذكيره بالتجديد.
- لوحة تحكم بسيطة (Admin Commands) لعرض عدد المشتركين النشطين والمنتهين.
